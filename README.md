# CruiseAI

CruiseAI is an iOS application that provides a safe and intelligent driving experience. The app uses the device's camera to monitor the road and provides real-time feedback to the driver.

## Features

- Camera access for road monitoring
- Start/Stop drive functionality
- Theme customization with multiple color options
- Trip tracking and summary
- Speed monitoring with visual indicators
- Object detection capabilities

## Requirements

- iOS 15.0+
- Xcode 13.0+
- Swift 5.5+

## Installation

1. Clone the repository
```bash
git clone https://github.com/ojaskandy/CruiseAI.git
```

2. Open the project in Xcode
```bash
cd CruiseAI
open CruiseAIios.xcodeproj
```

3. Build and run the application on your device or simulator

## Usage

1. Launch the app
2. Grant camera and location permissions when prompted
3. Tap "Start a Drive" to begin recording your trip
4. The app will monitor your speed and provide visual feedback
5. Tap "Stop Drive" when you're done to see a summary of your trip

## Customization

You can customize the app's theme by going to the Profile tab and selecting from the available color options.

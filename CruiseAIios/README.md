# CruiseAI - Modern Driving Assistant

CruiseAI is a sophisticated iOS driving assistant that combines real-time object detection, depth estimation, and speed monitoring with a stunning modern user interface.

## Design System

### Themes
The app features a modern theme system with four distinct color schemes:

- **Midnight**: Electric blue accents on deep midnight blue gradients
- **Sunset**: Warm orange accents on dark rose gradients
- **Aurora**: Neon green accents on deep teal gradients
- **Cosmic**: Bright purple accents on deep space purple gradients

### Glassmorphism Components
The UI utilizes a sophisticated glassmorphism design system:

- **GlassContainer**: Base container with frosted glass effect and theme-based accents
- **GlassButton**: Interactive buttons with glass effect and haptic feedback
- **GlassCard**: Information cards with semi-transparent backgrounds
- **ThemeSelector**: Visual theme picker with live previews

### Modern UI Features
- Smooth animations and transitions
- Dynamic color gradients
- Frosted glass effects
- Haptic feedback
- Floating action buttons
- Responsive layouts

## Key Features

### Real-time Detection
- Object detection with bounding boxes
- Visual depth estimation
- Speed monitoring and warnings
- Live camera feed processing

### Trip Tracking
- GPS route recording
- Speed analytics
- Trip summaries with maps
- Historical data

### User Experience
- Intuitive gesture controls
- Haptic feedback
- Voice alerts
- Dark mode optimized

## Technical Implementation

### Modern SwiftUI Architecture
- MVVM design pattern
- Observable state management
- Modular component design
- Reusable UI components

### Core Technologies
- SwiftUI for modern UI
- CoreML for object detection
- Vision framework for depth estimation
- CoreLocation for GPS tracking
- AVFoundation for camera handling

### Performance Optimizations
- Efficient rendering with SwiftUI
- Background processing for ML models
- Smart GPS filtering
- Memory-efficient state management

## Getting Started

1. Clone the repository
2. Open `CruiseAIios.xcodeproj` in Xcode
3. Build and run on an iOS device (simulator doesn't support camera features)

## Requirements
- iOS 15.0+
- Xcode 13.0+
- Swift 5.5+
- Physical iOS device for camera features
